# 📚 StudyStreak Demo

An interactive student productivity web application built with **React** to help students track study tasks and manage focus sessions effectively using a Pomodoro timer.

---

## ✨ Features

* ⏱️ **Pomodoro Focus Timer:** 25-minute study work sessions paired with automatic 5-minute break timers.
* 📝 **Interactive Task Management:** Add new daily study goals, mark completed tasks, or delete tasks dynamically.
* 🔥 **Streak Tracking Counter:** Visually keeps students motivated with continuous daily streak displays.
* 🎨 **Modern Dark Theme UI:** Designed for high contrast and reduced eye strain during long study sessions.

---

## 🛠️ Tech Stack

* **Frontend Library:** React.js (Hooks & Functional Components)
* **State Management:** `useState`, `useEffect`
* **Styling:** React Inline Styles (Tailwind CSS compatible layout)
